## 데이터 점검 결과 (2026-10-06)
- train 500 / test 1000, 모두 256×256 8bit 흑백(L), 누락·손상·완전 중복 없음
- train.csv 컬럼은 ID, hardness 두 개뿐 (안내문의 "세 가지 물성"은 실제 데이터에 없음)
- hardness: 평균 194.2, 표준편차 17.7, 범위 152.0~264.1, 약한 오른쪽 꼬리(skew 0.51)
- 이미지 구성: 다각형 결정립 + 어두운 경계선, 어두운 상 결정립, 둥근 어두운 기공, 결정립 신장·정렬, 잡음·흐림·조명 그라데이션 차이
- train/test 특징 분포 차이 작음 (특징별 KS 최대 0.08), test 예측 분포도 OOF 예측과 유사
- 파일 번호(ID) 순서와 정답·잔차 상관 없음 (ρ≈0) → ID 누수 없음

## 외부 사례 조사 요점
- 재료 정보학 표준: 2점 상관 통계(2-point statistics) + PCA + 회귀 (MKS 방식)
- 민코프스키 함수(면적·둘레·오일러 수): 다공성/2상 재료 물성 예측에 쓰이는 형태 기술자
- Mg-Gd 합금 경도 예측: 결정립 크기(선형 절편법), 2상 면적 비율, 2상 입자 등가 직경이 핵심 입력. 결정립 크기 영향이 가장 작았다는 보고 → 우리 결과와 일치
- Kaggle PetFinder(이미지 회귀, RMSE) 상위 해법: 미세조정 신경망 임베딩 + SVR 헤드를 신경망 헤드와 평균

## EDA에서 확인된 관계 (상관, 가설 단계)
- 어두운 상 관련(ph_mad, ph_frac) ↑ → 경도 ↑ (ρ≈+0.6, 가장 강함). 정밀한 결정립 단위 상 비율(ρ≈0.39)보다 픽셀 밝기 퍼짐 지표가 더 강함
- 상대 밝기 구간: 기지보다 8~24 어두운 면적 비율이 경도와 가장 강하게 연결 (ρ≈0.55)
- 2점 상관: 약하게 어두운 상(기지-10 미만)의 단거리(r=2~5px) 상관이 가장 강함 (ρ≈0.56). 약 25px 거리 상관은 기존 모델 잔차와도 상관(ρ≈0.12)
- 기공 수·면적 ↑ → 경도 ↓ (ρ≈-0.4)
- 정렬·신장 ↑ → 경도 ↑ (ρ≈+0.3)
- 결정립 크기: NLM+능선 검출 선형 절편법으로 정밀 측정(측정 간 일관성 높음)했으나 경도와 상관 거의 0. 깨끗한 이미지에서 Hall-Petch 항(1/√d) 편회귀 t≈-0.4 → 효과 없음
- 결정립 크기 분포 폭(log 면적 IQR, p90/p10) ↑ → 경도 ↑ (ρ≈+0.33~0.36), 잔차와도 약하게 상관(ρ≈0.10)
- 기각된 가설: 정렬 방향 각도, 방향×정렬 결합, 기공 크기 기반 배율 보정, 아주 작은 어두운 점

## 핵심 결론
- 리더보드(10/6): 1위 9.24, 10위 10.77, 중앙 약 12.2 → 초기의 "라벨 잡음 한계 약 13" 가설은 틀림
- 깨끗한 이미지에서 오차가 오히려 큼 (13.76 vs 나머지 12.70) → 측정 실패보다 "놓친 변수/관계" 문제
- 결정립 크기(Hall-Petch)는 정밀 측정에도 효과 없음 (미해결)
- 미세조정 CNN이 train조차 충분히 맞추지 못함 → CPU 학습량 부족 가능성. GPU 학습이 다음 핵심 실험
- **CV 개선(13.12 → 12.80)이 Public으로 옮겨가지 않음.** 파이프라인 버그는 없음(train/test 특징 분포·캐시·예측 분포 점검 완료). 300장 표본 시뮬레이션상 우연으로 나빠질 확률 약 1% → 같은 500장으로 수십 가지 조합을 고른 선택 편향(과적합)이 유력한 원인

## 분할 품질 메모
- NLM 잡음 제거: 경계 보존 우수. Sato 능선 + Otsu 임계값은 선명한 이미지에서 결정립계를 정확히 검출, 매우 흐린 이미지(약 39%)에서는 실패
- 기공: 어두운 상이 많은 이미지에서 상 결정립을 기공으로 오인 → 임계값 여러 개 사용
- watershed 결정립 수: 큰 결정립 이미지에서 과다 분할 → 선형 절편법으로 대체
