# 대회 공식 조건 정리 (확인일: 2026-10-05~06, 출처: DAKER 대회 페이지 안내/규칙/데이터 탭, 공식 참고자료 PDF)

## 확인된 사실
- 과제: 256×256, 8비트 흑백 PNG 미세구조 이미지 1장 → 경도 대용값(hardness, HV) 회귀
- 정답은 합성 대용값이며 실제 측정 경도가 아님
- 데이터: train 500장 / test 1,000장 (open.zip, 70.5MB, 참가 신청 후 다운로드)
- 파일: train/TRAIN_xxxxxx.png, test/TEST_xxxxxx.png, train.csv(ID, hardness), sample_submission.csv(ID, hardness)
- 평가: RMSE = sqrt(mean((pred - target)^2)), 낮을수록 좋음
- Public 30% / Private 70% (test 기준 → Public 약 300장), 동점 시 먼저 기록한 쪽 우선
- 최종 선택 제출: 1개
- 1차 평가: Private 100% / 2차: Private 상위 10명 코드+자료 제출 후 코드 검증
- 개인 참가만 가능, Python만 사용, 1일 최대 제출 5회
- 사전학습모델: 공식 가중치 공개 + 상업/비상업 이용 허용 라이선스(MIT, Apache 2.0, CC BY, CC BY-NC 등)만 허용
- 원격 API 모델 불가, 모든 모델 로컬 실행 가능해야 함
- 외부 데이터 불가, test는 어떤 형태로도 학습에 사용 불가
- 코드: 상대 경로, UTF-8, 오류 없이 실행, OS·라이브러리 버전 기재, Private Score 복원 가능
- 솔루션 자료: 자유 양식 PDF

## 공식 참고자료 PDF("미세구조 이해를 위한 참고 자료") 요점
- 정답은 Hall-Petch 관계, 상 혼합, 기공 영향을 본뜬 합성 대용값. 일반 물리 경향이 그대로 적용되는 것은 아님
- 이미지의 물리적 길이 스케일은 제공하지 않음
- 기공이 경도에 미치는 방향은 가정하지 말고 데이터로 학습할 것
- 정렬: 이미지의 "절대 방향"과 "정렬 정도"를 구분할 것
- 크기 분포의 균일성과 공간적 불균일성이 단서가 될 수 있음
